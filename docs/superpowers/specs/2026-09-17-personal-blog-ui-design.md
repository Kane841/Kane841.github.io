# 个人博客第一版外观设计

日期：2026-09-17  
状态：待审阅  
范围：视觉气质、色板、字体、动效、全站壳层与各页布局。不改功能、路由、frontmatter 或 `content/` 约定。功能见 [2026-09-17-personal-blog-design.md](./2026-09-17-personal-blog-design.md)。

## 背景与目标

在已定功能之上，做成深色、可阅读的个人站点：技术笔记为主，同时能给招聘方看项目。视觉走 ui-ux-pro-max 的 **Aurora UI**，但极光只做壳层氛围，正文落在高对比实心底上。

成功标准：实现后全站只有这一套深色青紫极光；导航、列表、详情、关于我、空态和 404 与本文布局一致；不要求改内容字段；静态导出后 GitHub Pages 可托管（无运行时特效依赖）。

## 非目标

- 浅色模式、主题切换、跟随系统
- 全页毛玻璃、WebGL、GSAP、卷轴剧场
- 搜索框、语言切换、评论 UI
- 插画空态、摄影 hero、独立 Logo 文件
- 改路由、frontmatter、`content/` 目录或发布流程

## 选定方案

**壳层极光 + 阅读实心底。** 画布与顶栏、卡片描边、标签带青紫光；段落、标题、代码在实心容器里读。这是为了避开 Aurora 在长文上的对比度与分心问题，同时保留极光辨识度。

已锁定的定制：

| 项 | 选择 |
|---|---|
| 主题色 | 青紫极光 |
| 明暗 | 只做深色 |
| 字体 | Outfit 标题 + Inter 正文 |
| 动效 | 克制 |
| 疏密 | 留白 + 16px 圆角 |
| 首页 | 短身份条 + 双入口 |
| 字标 | 纯文字站点名 |

## 设计原则

- 极光不穿过正文。卡片和文章栏是不透明底。
- 正文与背景对比度 ≥ 4.5:1；大标题 ≥ 3:1。
- 信息不只靠颜色：当前导航另有细条或光晕；标签有文字。
- 可点目标 ≥ 44×44px，间距 ≥ 8px；一律 `cursor: pointer`。
- `prefers-reduced-motion: reduce` 时背景静止，无入场动画。
- 图标用 Lucide 的 SVG，不用 emoji。
- 外观实现不得要求新增或改 frontmatter 字段。身份条只用 `site.config.ts` 的 `name` 与 `description`。

## 视觉 token

实现时写成 CSS 变量（Tailwind `@theme` 或等价），组件里不写死 hex。

### 色

| Token | 值 | 用途 |
|---|---|---|
| `--color-background` | `#0B1020` | 页背景 |
| `--color-foreground` | `#F8FAFC` | 主文字 |
| `--color-primary` | `#7C3AED` | 极光主色、强调描边 |
| `--color-on-primary` | `#FFFFFF` | 主色上的字 |
| `--color-accent` | `#22D3EE` | 辅色、链接、焦点环 |
| `--color-on-accent` | `#0B1020` | 辅色实心按钮上的字 |
| `--color-card` | `#12182A` | 卡片 / 正文栏 |
| `--color-card-foreground` | `#F8FAFC` | 卡片内主文字 |
| `--color-muted` | `#1A2238` | 弱背景 |
| `--color-muted-foreground` | `#94A3B8` | 日期、辅助说明；不作长文正文 |
| `--color-border` | `rgba(124, 58, 237, 0.28)` | 卡片边，可带极光 |
| `--color-ring` | `#22D3EE` | 键盘焦点 |
| `--color-destructive` | `#DC2626` | 仅错误态需要时 |

极光斑：两到三团径向渐变，主停靠 `--color-primary` 与 `--color-accent`，低透明度叠在 `--color-background` 上。正文区域不使用半透明白字压在纯渐变上。

### 字体

| 角色 | 字体栈 |
|---|---|
| 标题 / 字标 | `"Outfit", "Noto Sans SC", sans-serif` |
| 正文 / UI | `"Inter", "Noto Sans SC", sans-serif` |
| 代码 | `"JetBrains Mono", ui-monospace, monospace` |

基准 16px，正文行高 1.5。文章正文 16–18px。身份条标题约 32–40px。文章/项目详情标题约 32px。标签与导航可用 14px。`font-display: swap`。中文必须能正常显示，缺字回退到 Noto Sans SC，禁止用 Caveat 等手写体。

### 间距与形状

- 疏密：区块间距约 24–64px，卡片内边距约 16–24px。
- 内容最大宽 1120px，水平内边距移动端 16px、桌面 24–32px。
- 文章与项目详情正文栏最大宽约 720px。
- 卡片与正文栏圆角 16px；芯片全圆（999px）；按钮约 8–12px。
- 断点按移动优先：默认单列，约 768px 起首页双栏、项目列表双列，约 1024px 起完整顶栏导航。

### 动效

- 背景极光：8–12s 位移动画，循环、缓动、低幅度。
- 链接、按钮、卡片 hover：150–300ms 透明度/边框/微位移，不改宽高。
- 列表与正文无入场、无滚动剧场、无视差。
- `prefers-reduced-motion: reduce`：停掉背景动画，hover 可瞬间到位。

## 全站壳层

每页同一套壳，页面只换主区。

**跳过链接。** 文档流最前：「跳到正文」，默认视觉隐藏，聚焦时可见，目标为 `<main>`。

**顶栏。** 半透明 `--color-background`，轻微 backdrop-blur，滚动保持吸顶。左：纯文字站点名（`site.config.name`），Outfit，链到 `/`。右：首页、文章、项目、关于我，对应 `/`、`/articles`、`/projects`、`/about`。当前项用青色细条或淡紫光，不只靠变色。无搜索、无主题开关、无语言切换。窄屏：左字标、右菜单按钮（List 图标，`aria-label` 如「打开菜单」）；抽屉内同样四项，触控高度 ≥ 44px。

**主区。** `<main id>` 可被跳过链接对准。背景极光在主区之后、内容之下，`pointer-events: none`，不造成横向滚动。

**页脚。** 短一行：`RSS` 链到 `/rss.xml`；若关于我有 `socials` 则列出（外链或 `mailto:`）；版权用站点名。无大栏订阅表单。

**图标。** 社交、菜单、外链、RSS、返回：Lucide SVG。装饰性图标 `aria-hidden`；仅图标按钮必须有无障碍名。

## 组件

| 组件 | 做什么 | 如何用 | 依赖 |
|---|---|---|---|
| 极光背景 | 画布上的渐变斑 | 铺在 layout 底层 | token、reduced-motion |
| 顶栏 / 页脚 | 全站导航与次要链接 | layout 引用 | `site.config`；页脚社交来自 `about.md` 的 `socials`（有则列出） |
| 身份条 | 首页顶部名称 + 简介 | 仅首页 | `site.config.name/description` |
| 文章卡片 | 标题、日期、标签、摘要 | 首页、文章列表、标签页 | 文章字段；标签为链到 `/tags/:tag` |
| 项目卡片 | 标题、摘要、标签 | 首页精选、项目列表 | 项目字段；标签纯展示 |
| 标签芯片 | 展示或链接 | 文章可点，项目/技能不可点 | 同文字样式，交互不同 |
| 外链按钮 | 仓库 / 演示 / 简历 | 项目详情、关于我 | 仅当字段或文件存在 |
| Markdown 正文 | 渲染 Nuxt Content | 文章/项目详情、关于我简介 | prose 样式、代码块 token |
| 空态 | 一行说明 + 可选回链 | 见空态表 | 不增加内容字段 |
| 404 | 短说明 + 回首页 | `error` 页 | 功能规定的 404 情形 |

卡片：`--color-card` 底、16px 圆角、极光淡边。整卡可点时，标题是主链；文章标签单独可点，须避免嵌套交互冲突（标签是卡片内的独立链接，卡片其余点标题）。

## 页面布局

### 首页 `/`

自上而下：身份条（名称、一句话简介）→ 最新文章 → 精选项目。桌面两栏并排（左文章、右项目），窄屏先文章后项目。文章最多 5 条，链到 `/articles` 与单篇。项目为全部 `featured: true`，数量不封顶，卡片向下排，链到 `/projects` 与单篇。某侧 0 条则该侧空态，且不显示「查看全部」。身份条不新增字段。

### 文章列表 `/articles`

页标题「文章」。单列卡片，按 `date` 倒序。无筛选器、无搜索。点标题进详情，点标签进 `/tags/:tag`。

### 标签页 `/tags/:tag`

与文章列表同一套卡片。页头「标签：{tag}」。未知标签可访问、列表为空、不 404。

### 项目列表 `/projects`

页标题「项目」。桌面两列、窄屏一列。标签只展示。

### 文章详情 `/articles/:slug`

窄栏约 720px。返回「全部文章」到 `/articles`。标题、日期、标签、分隔、正文。代码块深底 + JetBrains Mono。标签可点。

### 项目详情 `/projects/:slug`

同样窄栏。返回「全部项目」。标题行可并列「仓库」「演示」（有 `repo` / `demo` 才出现），新标签打开外链。项目标签纯展示。然后摘要与正文。

### 关于我 `/about`

单栏，顺序：简介正文 → 技能栈芯片（不可点）→ 社交链接 → 简历下载。无 `public/resume.pdf` 时不渲染下载块，不留空按钮。

### 空态

不插画。一行说明，需要时加回链。

| 位置 | 表现 |
|---|---|
| 首页无文章 | 「还没有文章。」无「查看全部文章」 |
| 首页无精选 | 「还没有精选项目。」无「查看全部项目」 |
| `/articles` 或 `/projects` 为空 | 「还没有内容。」 |
| 未知标签 | 「没有带这个标签的文章。」+ 回 `/articles` |
| 关于我无简历 | 不出现下载区 |

### 404

居中：「没有这个页面。」+ 回首页。未知 slug、draft 文章直链、其他未知路径都用这一页。壳层仍在。

### 无独立外观的路由

`/rss.xml` 不是 HTML 页，只在页脚给文字链。`/resume.pdf` 是文件下载，不是页面。

## 外观技术选型

在功能已定的 Nuxt + Nuxt Content + 静态导出之内：

- Tailwind CSS，语义色进 CSS 变量（Tailwind 3 用 `theme.extend`，Tailwind 4 用 `@theme`），禁止组件内散落 hex。
- 极光用 CSS 径向/网格渐变 + `@keyframes`，不用 canvas/WebGL。
- 字体用 Google Fonts 或自托管，须可静态导出。
- 站内链 `NuxtLink`；外链 `<a target="_blank" rel="noopener noreferrer">`。
- Markdown 用 Nuxt Content 渲染器 + 统一 prose，含标题层级、列表、代码、链接。
- 页面 SEO 用 `useSeoMeta`（标题、描述）；这是呈现元信息，不改内容模型。

不引入：主题切换库、i18n、评论组件、搜索 UI、GSAP。

## 响应式

- 375px：单列，汉堡菜单，芯片换行，详情仍窄栏。
- 768px：首页可双栏，项目列表可双列。
- 1024px+：完整顶栏，内容最大 1120px 居中。
- 禁止横向滚动。触控目标不贴齐屏幕手势区。

## 无障碍

- 跳过链接、顺序标题（每页一个 `h1`）、可见焦点环（`--color-ring`，至少 2px）。
- 菜单按钮、纯图标按钮有 `aria-label`；展开菜单有开合状态。
- 装饰性极光与图标不进无障碍树。
- 当前导航不仅靠颜色。
- 尊重减少动态。

## 与功能文档的边界

外观可以改：layout、组件、CSS、字体、空态文案的具体用词（上表已定）。

外观不可以改：路由表、draft/featured/标签规则、RSS 字段、简历探测逻辑、frontmatter 必填项。

功能测试仍只测功能。本文的验收是实现时人工对照：色、字体、壳层、各页结构、空态、reduced-motion、窄屏单列。

## 模块边界

| 模块 | 做什么 | 如何使用 | 依赖 |
|---|---|---|---|
| 设计 token | 色、字、间距、圆角、动效变量 | 全局 CSS / Tailwind theme | 无 |
| 布局壳 | 跳过链接、顶栏、极光、页脚、`<main>` | 各页套用 | token、`site.config` |
| 内容卡片 | 把已查询的文章/项目画成列表项 | 首页与列表页 | 功能层查询结果 |
| 正文呈现 | Markdown 与元信息排版 | 详情与关于我 | Nuxt Content、token |
| 空态 / 404 | 无数据或未知路径的呈现 | 功能层判定之后 | 功能规则 |

查询、发布、内容文件不属于外观模块。
